# Recuperação JavaScript Essentials 1 - Módulo 6

## Exercícios escolhidos
Foram selecionados os exercícios **1, 2, 4, 6 e 7**. Cada exercício está em um arquivo JavaScript separado, com funções nomeadas, comentários e testes executáveis.

## Requisitos
- Node.js 18 ou superior (recomendado).
- VS Code.

## Como executar
1. Baixe e extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra o terminal integrado: **Terminal > Novo Terminal**.
4. Execute um arquivo por vez:

```bash
node 01-erros-excecoes-falhas.js
node 02-silent-failures.js
node 04-dominios-cause-stack.js
node 06-finally-preservar-erros.js
node 07-erros-personalizados-serializacao.js
```

Os exercícios 2, 6 e 7 possuem asserts para verificar os comportamentos esperados. O exercício 1 simula uma falha fatal usando `process.exitCode = 1`, sem encerrar abruptamente o terminal durante a demonstração.

## Publicação no GitHub
1. Crie um repositório público, por exemplo `recuperacao-javascript-modulo-6`.
2. Envie todos os arquivos desta pasta.
3. Copie a URL do repositório e entregue no Classroom.
